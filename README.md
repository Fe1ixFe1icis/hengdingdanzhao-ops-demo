# 单招运营工作台 · 演示版

面向湖南单招教培机构的 AI 新媒体运营一体化工作台（演示试用版）。纯静态、零依赖、可直接部署到 **GitHub Pages**。

> ⚠️ 本目录是**公开演示版**：全流程可体验，但导出/下载均为**带水印的预览**，不产出可用成品。
> 完整功能版与真实资产不在此目录，见 `../private/`（不纳入公开仓库）。

---

## 一、目录结构

```
public/                    ← 本目录，即 GitHub Pages 部署根
├── index.html             入口（单页应用，相对路径，无构建）
├── assets/
│   ├── styles.css         样式（三色笔记配色 + 演示水印）
│   ├── app.js             UI 与五大模块
│   ├── adapter.client.js  前端适配层：存储 / 解析器 / 渲染 / 导出锁定
│   ├── protect.js         防护层：水印 / 禁复制 / 快捷键拦截 / 失焦遮罩
│   └── api.contract.md    前后端分离接口契约
├── data/
│   ├── syllabus.js        内嵌考纲（长沙民政 9 个专业组 + 数学，自动生成）
│   └── presets.js         提示词库 / 话术库 / 30天排期 / 合规词库 / 示例成品
├── .nojekyll              GitHub Pages 需要（避免下划线目录被忽略）
└── README.md
```

## 二、本地预览

直接双击 `index.html` 用浏览器打开即可（`file://`）。
> 注意：`file://` 下 `localStorage` 按文件路径隔离，**移动或改名会导致数据"丢失"**，请保持路径固定。

## 三、部署到 GitHub Pages

1. 新建仓库（可为 Public），把**本目录内容**作为仓库根推上去：
   ```bash
   cd public
   git init
   git add .
   git commit -m "init demo"
   git branch -M main
   git remote add origin git@github.com:<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
2. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` / `(root)` → Save。
3. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

全部为相对路径，无需任何构建步骤或环境变量。

## 四、演示防护说明（重要）

| 已启用 | 说明 |
|---|---|
| 全页水印 | 「演示试用版本」平铺水印覆盖全部页面 |
| 禁止复制 | 禁用选中 / 右键 / 复制 / 剪切 / 拖拽 / 打印 |
| 快捷键拦截 | `Ctrl/Cmd + C X S P U A`、`F12`、`Ctrl+Shift+I/J/C` |
| 失焦遮罩 | 切换标签页 / 窗口失焦时遮罩隐藏内容 |
| 开发者工具检测 | 检测到后暂停演示内容并提示 |
| 导出锁定 | 下载/导出 → 仅生成**带水印的预览图**，不产出可下载文件 |

> **必须诚实说明**：纯前端防护本质上是**威慑**，懂技术的人可以通过改 JS、断网执行、开发者工具等方式绕过。真正有效的保护是把关键内容放在服务端、只下发水印后的结果。
> 本项目的 `assets/adapter.client.js` 是「前后端分离」的接缝：把导出渲染、提示词库等关键能力迁移到私有后端（`HttpAdapter`）即可升级为硬保护，UI 无需改动。

## 五、AI 接入（让生成按钮真正调用大模型）

工作台内置 **OpenAI 兼容协议** 的 AI 客户端，在 **设置 → AI 接入** 填入即可用：

1. **服务商**（快捷填充）：DeepSeek / 通义千问 / 智谱 GLM / Kimi / 硅基流动 / OpenAI / 自定义。选择后自动填好 Base URL 与模型名（模型名更新较快，请以各平台控制台为准）。
2. 填写 **Base URL、模型名、API Key**，点「测试连通」验证。
3. 保存后，「考纲解析」与「内容生产」里的 **🤖 AI 直接生成** 按钮即可一键调用，结果边生成边显示，并自动解析成三色笔记 / 文案草稿。

> - Key 只存在本机浏览器 localStorage，不上传任何服务器。
> - 也可不用 API：走「复制提示词 → 豆包/DeepSeek 网页版 → 粘回」的手动通道，功能完全等价。
> - **CORS 提示**：浏览器直连需服务商允许跨域。若报网络失败，请改用 http(s) 打开（本地可 `python -m http.server`），或换用允许 CORS 的服务商，或走手动通道。

## 六、数据存储

- 所有数据存在**浏览器 localStorage**（命名空间 `dzops.v1.*`），不上传服务器。
- 换设备 / 清缓存会丢失；演示版出于保护**禁用了备份导出与清空**。
- 首次打开会自动写入预置数据（30 天排期、提示词库、话术库、考纲字典、合规词库）。

---

## 七、替换考纲数据

`data/syllabus.js` 由脚本自动生成。要换成别的学校/专业组：

1. 把考纲 `.docx` 放到 `../` 可访问的位置；
2. 修改 `../tools/extract_syllabus.py` 中的文件清单；
3. 运行：`python ../tools/extract_syllabus.py`，会重新生成 `data/syllabus.js`。
